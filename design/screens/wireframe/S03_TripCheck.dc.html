트립 체크

진입: S01 진행 중 카드 / S02 [트립 만들기] 목적: 트렁크 앞에서 한 손으로 아이콘을 탭해 챔김 여부를 기록
미챔김 챔김 제외(이번엔 안 가져감)
No구성 요소설명
1앱바 + 진행트립명, 챔김 n / 전체 m(제외 아이템은 m에서 빼고 계산), 아래 진행바. 스크롤해도 고정
2정렬 · 추가[미챔김 우선]: 미챔김 아이템을 각 카테고리 앞에 정렬. [카테고리순]: 세트 순서 그대로. [+ 아이템] → S04 바텀시트
3카테고리 헤더카테고리명 + 카테고리 내 챔김/전체. 헤더 탭 → 카테고리 접기/펴기
4아이템 타일72px 아이콘 + 이름 + 수량 뱃지(2개 이상일 때만). 탭 = 미챔김 ↔ 챔김 토글. 롱프레스 = 액션 시트(제외 / 수량 변경 / 트립에서 삭제). 제외 타일은 탭해도 상태 안 바뀜, 롱프레스로만 복귀
5캠핑 완료미챔김이 남아 있으면 "미챔김 n개가 있습니다" 확인 후 완료. 완료 시 트립 잠금(읽기 전용) → S01
비기능: 오프라인 전제, 화면 자동 꺼짐 방지(이 화면에서만), 타일 간격 10px 이상으로 오탭 방지. 체크 상태는 탭 즉시 저장(별도 저장 버튼 없음). 아이콘 미제작 아이템은 카테고리 아이콘으로 폴백.
