진입: S03 [+ 아이템] / S02 [세트 없이 시작] 목적: 세트에 없던 아이템을 이번 트립에만 추가
No구성 요소설명
1검색이름 부분 일치, 입력 즉시 필터. 시트 열릴 때 자동 포커스 없음(트렁크 앞 사용 전제, 키보드 강제 노출 방지)
2카테고리 칩가로 스크롤. 트립에 이미 전부 담긴 카테고리는 표시하지 않음
3아이템 행트립에 없는 아이템만 노출. 아이콘·이름·카테고리(커스텀 표기). 우측 [+] 탭 → 선택 토글(다중 선택). 수량은 기본 수량으로 추가, 변경은 S03 롱프레스에서
4커스텀 만들기→ S08. 저장 후 이 시트로 복귀하며 해당 아이템 선택 상태
5추가 버튼선택 개수 표시. 미챔김 상태로 트립에 추가 → S03 닫기. 0개면 비활성
시트로 만든 이유: 체크 도중 "아 이것도" 하는 상황이 대부분이므로 S03 컨텍스트를 유지해야 함. 시트 밖 딤 영역 탭 = 선택 취소 없이 닫기.
