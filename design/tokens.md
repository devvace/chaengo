# 챙고 디자인 토큰 (v0.1 확정)

톤: 밝고 건조한 유틸. 백색 바탕, 잉크 블랙, 포인트 1색(그린 = 챔김). 그림자 없음, 선으로 구분.

## 색

| 토큰 | HEX | 용도 |
| --- | --- | --- |
| bg | #FFFFFF | 화면 바탕 |
| surface | #F4F4F2 | 담긴 타일 배경, 비활성 칩, 캔버스 바탕 |
| line | #E4E4E0 | 구분선(1px) |
| lineStrong | #D6D6D2 | 타일·칩·버튼 테두리(1.5px) |
| ink | #111111 | 본문, 주요 버튼 배경, 담긴 타일 테두리 |
| inkSub | #5C5C5C | 보조 텍스트 (백색 위 7.0:1) |
| inkMute | #8A8A85 | 비활성 라벨, 안 담김 아이콘 |
| done | #157A48 | 챔김 타일 배경, 진행바. 이 색은 챔김 상태에만 쓴다 |

| cardDark | #111111 / 텍스트 #FFFFFF / 보조 #B5B5B0 / 선 #2C2C2A | 홈 진행 중 카드 |

## 아이콘

- 단색 벡터, tint로 색 적용. 파일: design/icons/. 인덱스와 라이선스: design/icons/INDEX.md, LICENSE-game-icons.txt.
- 타일 안 아이콘 크기 44 (76 타일), 홈 미리보기 26 (44 타일), 리스트 행 24 (40 타일).
- 아이콘 없는 아이템은 카테고리 아이콘으로 폴백.
- 하단 탭 아이콘은 1.8px 스트로크 라인(체크박스, 레이어, 4분할 그리드, 톱니). 아이템 아이콘(실루엣)과 구분되는 게 의도.

## 인터랙션

- 타일 탭 = 즉시 상태 토글 + 즉시 저장(저장 버튼 없음). 탭 시 짧은 햅틱(설정에서 끌 수 있음).
- 타일 롱프레스 = 액션 시트(S03: 제외 / 수량 / 삭제, S06: 수량).
- S03에서만 화면 자동 꺼짐 방지.
- 오프라인 전제. 네트워크 호출 없음.
