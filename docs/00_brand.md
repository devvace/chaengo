# 챙고 (CHAENGO) 서비스 브랜드 정의서

2026-09-18 · @Ace

## 서비스 개요

- **서비스명**: 챙고 (CHAENGO)
- **태그라인**: 챙기고, 떠나고. / 빠진 거 없이, 챙고.
- **한 줄 정의**: 오토캠퍼의 캠핑 장비를 관리하고, 출발 전 짐을 빠짐없이 체크하는 모바일 앱
- **카테고리**: 라이프스타일 / 유틸리티 (iOS·Android)
- **1차 파일럿 대상**: 아이템이 많은 오토캠퍼, 캠핑 횟수 월 1회 이상

## 이름 어원

**챙기고 → 챙고.** 캠퍼들이 출발 전 서로 묻는 말 그대로다. "다 챙겼어? 고!"를 줄이면 챙고가 된다.

읽는 순간 **창고**로도 들린다. 오토캠퍼는 베란다·차고·트렁크 어딘가에 장비 창고를 하나씩 두고 있다. 이 앱이 그 창고를 주머니 안에 넣어주는 것이다.

두 의미가 하나의 발음에 겹쳐 있어, 이름 자체가 서비스의 핵심 동작(짐을 창고에서 꺼내 챙긴다)을 설명하다.

## 세계관 구조

창고 → 트렁크 → 캠핑장으로 이어지는 3단 흐름이 서비스 전체를 괠통한다.

| 단계 | 은유 | 기능 | 출시 시점 |
| --- | --- | --- | --- |
| 창고 | 내 전체 장비 | 아이템 DB + 세트 관리 | 1차 파일럿 |
| 트렁크 | 이번에 실을 것 | 트립 체크리스트 | 1차 파일럿 |
| 캠핑장 | 다녀온 기록 | 지도 + 사진 다이어리 | 2차 이후 |

세트 이름에도 은유가 자연스럽게 붙는다. 여름 트렁크, 겨울 트렁크, 감성 트렁크처럼 "트렁크"를 세트의 별칭으로 쓸 수 있다. 2차에 붙을 지도·사진 기능은 "추억 창고"로 같은 세계관 안에 들어온다.

## 네이밍 검토 이력

### 채비 — 탈락

의미 적합도가 가장 높았으나 두 가지 이유로 제외했다.

- [채빗(CHAEBIT)](https://apps.apple.com/sa/app/%EC%B1%84%EB%B9%97-%EC%97%AC%ED%96%89-%EC%B2%B4%ED%81%AC%EB%A6%AC%EC%8A%A4%ED%8A%B8/id6466760833): 여행 체크리스트 앱. 슬로건에 '채비'를 그대로 쓰고, 매번 챙기는 준비물을 템플릿으로 저장하는 기능까지 동일하다. 기능·키워드 양쪽이 겹친다.
- 채비(CHAEVI): 전기차 충전 브랜드로 사용 중. 상표 9류·42류 충돌 가능성이 있다.

### 챙고 — 채택

웹 검색 1회 기준 유사 캠핑 앱 미발견. **출시 전 아래 세 가지를 직접 확인해야 한다.**

- [ ] 키프리스 상표 검색 (9류: 소프트웨어, 42류: SaaS)
- [ ] App Store · Google Play 검색
- [ ] 도메인 확인: chaengo.app / chaengo.kr

### 대안 후보 (챙고 탈락 시)

- **캠토리**: 인벤토리(Inventory) + 스토리(Story) 합성. 장비 관리와 기록 양쪽에 걸린다.
- **박수**: 캠퍼가 세는 '박(泊)' + 수. 숙박 기록 중심으로 확장할 때 강하다.

## 다른 채팅에서 참고할 때

이 문서를 새 채팅에 링크하거나 내용을 붙여넣을 때 함께 전달할 컨텍스트다.

**서비스**: 챙고(CHAENGO) — 오토캠퍼용 캠핑 짐 체크리스트 앱. 서버·로그인 없음, 기기 내 저장.

**1차 파일럿 기능 (구현 완료 기준)**

- 아이템 관리: 앱 내장 기본 아이템 + 커스텀 아이템, 카테고리 9개 고정
- 세트 관리: 상황별 아이템 묶음(여름·겨울·감성 등) 저장·복제
- 트립 체크: 세트를 복사해 트립 생성 → 아이콘 탭으로 챔김/미챔김 토글 → 완료 처리

**2차 이후**: 방문 캠핑장 지도 표시 + 사진 업로드(다이어리), 클라우드 동기화, 세트 합성

**관련 산출물** (이 대화에서 생성)

- 요구사항 정의서: 캠핑 체크리스트 앱 요구사항 정의서 (v0.1)
- 화면 설계서: 챙고 화면 설계서 — 흐름도 1장 + 화면 9장(S01\~S09), 아트보드 간 링크 연결
