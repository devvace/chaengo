# 챙고(CHAENGO) 요구사항 정의서 (v0.1)

2026-09-18 · @Ace

**서비스명(가칭)**: 챙고(CHAENGO) — 확정

**1차 파일럿 범위**: 캠핑 아이템 체크리스트 1개 기능. 로그인·서버 없음(기기 내 저장). 지도·사진·다이어리는 2차 이후.

**파일럿 성공 기준**: 파일럿 참여자 중 2회 이상 트립을 생성한 비율 50% 이상(기간·인원은 별도 확정).

# 사용자

## 서비스 - 아이템 관리

### 필요 기능

- 기본 아이템 제공
- 커스텀 아이템 추가
- 아이템 수정/삭제
- 아이템 검색
- 아이템 아이콘 지정

### 기능 설명

- 카테고리(텐트·타프 / 침구 / 조리 / 화기 / 조명 / 전력 / 위생 / 의류 / 기타) 단위로 앱 내장, 파일럿 기준 100개 이내
- &#91;이름\], \[카테고리\], \[아이콘\], \[기본 수량\] 입력
- 기본 아이템은 삭제 불가·숨김 가능, 커스텀 아이템은 삭제 가능
- 이름 기준 검색, 카테고리 필터
- 기본 아이콘 세트 또는 이모지 중 선택. 사진 아이콘은 2차 이후

### 레퍼런스

- PackPoint(범용 패킹 앱) — 아이템 카테고리 구조 참고, URL 조사 후 기입

---

## 서비스 - 세트 관리

### 필요 기능

- 세트 생성
- 세트 아이템 담기/빼기
- 세트 복제
- 세트 수정/삭제
- 기본 세트 제공

### 기능 설명

- &#91;세트 이름\], \[아이템 목록(수량 포함)\]로 구성. 예: 여름, 겨울, 감성캠핑
- 아이템 아이콘을 탭하여 세트에 담기/빼기, 담긴 아이템은 강조 표시
- 기존 세트를 복제해 파생 세트 생성(여름 → 여름+감성). 세트 합성(태그/레이어)은 2차 이후
- 세트 수정은 이미 생성된 트립에 영향 없음
- 기본 세트 1개 앱 내장("기본 오토캠핑"), 사용자 삭제 불가·수정 가능

### 레퍼런스

- 조사 후 기입

---

## 서비스 - 트립 체크리스트

### 필요 기능

- 트립 생성
- 트립 아이템 조정
- 패킹 체크
- 진행률 표시
- 트립 완료/이력
- 트립을 세트로 저장

### 기능 설명

- &#91;트립 이름\], \[날짜\], \[세트\] 선택으로 생성. 생성 시 세트 아이템이 트립으로 복사되어 원본 세트와 분리
- 트립 안에서 아이템 추가/제외 가능. 제외("이번엔 안 가져감")는 패킹 체크와 별도 상태
- 아이콘 탭으로 챔김/미챔김 토글. 아이템 상태 3종: 미챔김 / 챔김 / 제외
- 상단에 챔김 n / 전체 m 표시, 미챔김 아이템 우선 정렬 옵션
- 캠핑 후 완료 처리, 완료 트립 목록 조회(이력은 2차 다이어리 기능의 기반)
- 완료 트립의 구성을 새 세트로 저장(다음 캠핑 재사용)
- 비기능: 오프라인 동작 필수, 체크 화면 자동 꺼짐 방지, 터치 타겟 최소 48dp(한 손·짐 든 상태 전제)

### 레퍼런스

- 조사 후 기입

---

## 서비스 - 데이터 관리

### 필요 기능

- 로컬 저장
- 백업/복원
- 데이터 초기화

### 기능 설명

- 로그인 없음, 전체 데이터 기기 내 저장(SQLite)
- JSON 파일 내보내기/가져오기로 기기 교체 대응. 클라우드 동기화는 2차 이후
- 전체 초기화 시 기본 아이템·기본 세트만 남김

### 레퍼런스

- 조사 후 기입

---

# 관리자

## 서비스 - 기본 데이터 관리

### 필요 기능

- 기본 아이템 DB 관리
- 기본 세트 관리
- 아이콘 에셋 관리
- 사용 지표 수집

### 기능 설명

- 파일럿은 관리자 화면 없음. 기본 아이템은 앱 내장 JSON으로 관리, 앱 업데이트로 배포
- 기본 세트도 동일 방식
- 아이콘 목표 수량: 카테고리 9개 + 아이템 100개. 미제작 아이템은 카테고리 아이콘으로 폴백. 일정상 최대 리스크 항목
- 지표: 트립 생성 수, 트립당 체크 완료율, 2회 이상 트립 생성 비율. 익명 이벤트 수집 도입 여부 결정 필요(로컬 온리 원칙과 상충)

### 레퍼런슬

- 조사 후 기입

---

## Out of Scope (2차 이후)

- 다이어리: 방문 캠핑장 지도 표시 + 사진 업로드 + 방문 기록(한 덩어리로 2차)
- 회원가입/로그인, 클라우드 동기화
- 세트 합성(태그/레이어)
- 아이템 사진 아이콘
- 세트 공유, 커뮤니티

## 중요도

- 1순위: 트립 체크리스트
- 2순위: 세트 관리
- 3순위: 아이템 관리
- 4순위: 데이터 관리
- 5순위: 관리자 - 기본 데이터 관리

구현 순서는 의존성상 아이템 → 세트 → 트립이며, 중요도는 사용자 가치 기준.
