# 챙고 화면 설계서 (v0.1 확정) — 텍스트 사양

와이어프레임 원본: design/screens/wireframe/*.dc.html (각 파일 오른쏙 `<aside class="spec">`에 같은 표가 들어 있다).
하이파이 원본: design/screens/hifi/ (S01·S03·S06 + 스타일 타일 + 아이콘 시트). 나머지 화면은 design/tokens.md 규칙으로 동일하게 구현.

## 화면 흐름

```
하단 탭: S01 트립(홈) | S05 세트 | S07 창고(아이템) | S09 설정

S01 트립 목록 ── [새 트립] ──▶ S02 트립 생성 ── [만들기] ──▶ S03 트립 체크 ── [+ 아이템] ──▶ S04 아이템 추가 시트
   │                                                      │
   └─ 진행 중 카드 ─────────────────────────────────────────┘
   └─ 완료 트립 [세트로 저장] ──▶ S06 세트 편집

S05 세트 목록 ── [편집][복제][새 세트] ──▶ S06 세트 편집 ── [+ 커스텀] ──▶ S08
S07 아이템 목록 ── 행 / [추가] ──▶ S08 아이템 추가·수정
S04 [커스텀 만들기] ──▶ S08 (저장 후 복귀, 자동 선택)
```

## 도메인 모델 (3층)

- Item: id, name, categoryId(고정 9개), iconKey, defaultQty, isBuiltIn, isHidden
- Set(템플릿): id, name, isBuiltIn, lastUsedAt, items[{itemId, qty}]
- Trip: id, name, startDate, endDate, sourceSetId, status(active|done), items[{itemId, qty, state(unpacked|packed|excluded)}]
- Trip.items는 생성 시 Set에서 **복사**. 이후 Set 변경은 Trip에 영향 없음.
- 진행 중(active) Trip은 동시에 1개만.
- 카테고리 9개 고정: 텐트·타프 / 침구 / 조리 / 화기 / 조명 / 전력 / 위생 / 의류 / 기타

## S01 트립 목록 (홈) — 탭 1

| No | 구성 요소 | 설명 |
| --- | --- | --- |
| 1 | 앱바 | 워드마크 "챙고" 26/700 + "CHAENGO" Mono 11 inkMute. 우측 오늘 날짜 |
| 2 | 진행 중 카드 | 검은 카드. 트립명, 날짜·원본 세트명, 큰 숫자 챔김/전체, 남은 개수, 진행바. 카드 전체 탭 → S03. 아래에 "아직 안 챙김" 미리보기 4개 + n. 진행 중 없으면 안내 문구 + [새 트립] |
| 3 | 완료 리스트 | 최신순. 이름, 날짜, Mono 챔김/전체. 우측 pill [세트로 저장] → S06(트립 구성 복사, 이름 기본값 = 트립명). 이미 저장했으면 회색 "저장됨" |
| 4 | 새 트립 | 보조 버튼(백색+ink 테두리), 하단 고정 → S02 |
| 5 | 하단 탭 | 트립 / 세트 / 창고 / 설정 |

규칙: 진행 중 트립이 있을 때 [새 트립] → "기존 트립을 완료 처리할까요?" 확인.

## S02 트립 생성

| No | 구성 요소 | 설명 |
| --- | --- | --- |
| 1 | 트립 이름 | 필수. 기본값 "세트명 + 월"(예: 감성캠핑 9월) |
| 2 | 날짜 | 시작·종료. 기본값 이번 주 토·일. 표시용, 알림 없음 |
| 3 | 세트 선택 | 단일 라디오. 세트명·아이템 수. 마지막 사용 세트 기본 선택. [세트 없이 시작] → 빈 트립 생성 후 S04 바로 열기 |
| 4 | 트립 만들기 | 세트 아이템 복사 → S03. 이름 비면 비활성 |

## S03 트립 체크 — 핵심

| No | 구성 요소 | 설명 |
| --- | --- | --- |
| 1 | 앱바 + 진행 | 뒤로, 트립명, ⋯(완료 취소·이름 변경·삭제). 아래 Mono 큰 숫자 챔김/전체(제외는 전체에서 뺀다), "타프 1개 제외 · 22개 남음", 진행바. 스크롤 시 고정 |
| 2 | 정렬·추가 | 칩 [안 챙긴 것 먼저](기본) / [카테고리순]. 우측 원형 [+] → S04 |
| 3 | 카테고리 헤더 | 이름 14/600 + Mono 챔김/전체. 탭 → 접기 |
| 4 | 타일 그리드 | 4열 76px. **탭 = 미챔김↔챔김**. **롱프레스 = 액션 시트(제외/수량/트립에서 삭제)**. 제외 타일은 탭 무반응, 롱프레스로만 복귀. 수량 2+만 뱃지 |
| 5 | 캠핑 완료 | 하단 고정 ink 버튼 + Mono "n개 남음". 남은 게 있으면 확인 후 완료. 완료 = 잠금(읽기 전용) → S01 |

비기능: 이 화면만 화면 꺼짐 방지. 탭 즉시 저장. 탭 햅틱.

## S04 아이템 추가 시트 (S03 위 바텀시트, 높이 ~76%)

| No | 구성 요소 | 설명 |
| --- | --- | --- |
| 1 | 검색 | 이름 부분 일치. 자동 포커스 없음(키보드 강제 노출 방지) |

| 4 | 커스텀 만들기 | → S08, 저장 후 시트 복귀 + 선택 상태 |
| 5 | n개 추가 | 미챔김 상태로 트립에 추가 → 시트 닫힘. 0개 비활성 |

딤 영역 탭 = 닫기(선택 취소 안 함).
